# Everything needed to run and test ADII.
#
#   python3 -m venv .venv
#   source .venv/bin/activate        # Windows: .venv\Scripts\activate
#   pip install -r requirements.txt
#
# The first line installs this repository itself, so `import adii` and
# `python -m adii.demo` work from anywhere. The rest are the test and lint tools.
# Runtime dependencies are deliberately few and pinned. Anything added here has to earn
# its place in review.

-e .

# Pinned for the same reason as ruff: the clean-clone path and CI both consume this

# with nothing in the repository having changed. 9.1.1 is what two clean clones qualified.
pytest==9.1.1

# Pinned, not floated. CI gates on lint, and an unpinned linter turns a new ruff
# release into a red build nobody caused. Bump it deliberately, in its own PR.
